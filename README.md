# 每日一言 · 小米手环 10 Pro

一个完全离线的 Vela 小游戏。每天根据手环本地日期固定抽出一句话和一个签级，无需网络或服务器。界面采用米白纸张、墨色文字与朱红印章构成的纸质日历风格。

## 玩法

- 点击“翻开今日一签”查看当天固定语句和签级；签级分为上上签、上签、中签、下签、下下签。
- 进入“脑筋急转弯”，按本地日期浏览当天固定的 20 道离线题目。
- 当天首次看完 20 道题可获得 1 点灵光；连续来访会累计连续天数。
- 可收藏喜欢的句子，也可点击“换一句”自由浏览。
- 语录下方提供今日日历、近似月相和十二星座信息；星座可左右切换并保存在本地。
- 右滑或点击右上角“退出”离开应用。

所有进度都保存在手环本地。内置 2000 条真实一言数据，不会在手环上发起网络请求。语录来自一言开源社区官方语句库中的原创、网络和哲学分类，每条保留官方 UUID、出处和作者信息；不使用模板组合，也不收录诗词分类。

官方原始数据位于 `data/hitokoto-source`，筛选后的 2000 条完整记录位于 `data/hitokoto-selected.json`。超过 100 道纯脑筋急转弯及扩展资料位于 `data/riddles.json`；运行包只会内联真正的脑筋急转弯。构建前会重新筛选、去重并内联到页面；自动校验会检查语录数量、UUID、来源、全文去重、短屏长度，以及题库字段和题目去重。授权说明见 `THIRD_PARTY_NOTICES.md`。
