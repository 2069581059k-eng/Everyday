# 每日一言 · 小米手环 10 Pro

一个完全离线的 Vela 小游戏。每天根据手环本地日期固定抽出一句话和一个签级，无需网络或服务器。界面采用米白纸张、墨色文字与朱红印章构成的纸质日历风格。

## 玩法

- 点击“翻开今日一签”查看当天固定语句和签级；签级分为上上签、上签、中签、下签、下下签。
- 进入“知识大全”，按本地日期浏览当天固定的 20 道离线题目；每天包含 7 道脑筋急转弯、6 道十万个为什么和 7 道百科知识。
- 当天首次看完 20 道题可获得 1 点灵光；连续来访会累计连续天数。
- 可收藏喜欢的句子，也可点击“换一句”自由浏览。
- 语录下方提供今日日历、近似月相和十二星座信息；星座可左右切换并保存在本地。
- 右滑或点击右上角“退出”离开应用。

所有进度都保存在手环本地。1.7.1 内置 2000 条一言和 2297 条知识内容，不会在手环上发起网络请求。语录来自一言开源社区官方语句库中的原创、网络和哲学分类，每条保留官方 UUID、出处和作者信息；不使用模板组合，也不收录诗词分类。

官方一言原始数据位于 `data/hitokoto-source`，筛选后的 2000 条完整记录位于 `data/hitokoto-selected.json`。三类知识题位于 `data/knowledge-selected.json`，组成如下：

- 脑筋急转弯 400 条：来自 `ChineseDatasets / brainteasers`，只保留源答案本身已经能说明转折点的记录。
- 十万个为什么 750 条：原有 600 条，加用户内容包中的 150 条生活常识。
- 百科知识 1147 条：原有 1000 条，加用户内容包中的 147 张动物知识卡。

本次将用户提供的《米环综合内容库_V2_最终2000条.zip》与旧库合并，按规范化问题/标题、来源记录和知识卡全文去重。1703 条重复项的答案和解析完全一致，保留旧库版本，净增加 297 条，合计 2297 条，低于 5000 条上限。近似标题复核中的“黑猩猩”和“倭黑猩猩”是不同动物，均保留。

CMRC 2018 的解析取自原文句；脑筋急转弯保留源解释。本次新增的 297 条没有外部出处和许可证，按用户提供原文导入，未逐条独立核实，不将其标为已验证的公开来源数据。原包主 JSON、旧库基线保存在 `data/merge-inputs`；压缩包 SHA-256、逐条重复映射和来源缺失统计见 `data/knowledge-sources.json` 与 `data/knowledge-merge-report.json`。动物内容以知识卡阅读；长答案完整进入分页详情。授权说明见 `THIRD_PARTY_NOTICES.md`。

## 验证与构建

```powershell
cd "C:\Users\20695\Documents\huarongdao\daily_quote_10pro"
npm.cmd test
npm.cmd run build
npm.cmd run package:release
```

运行 `npm.cmd run data:refresh` 可从保存在仓库中的旧库基线和用户主 JSON 重现本次合并；日常构建完全离线。`tools/import-knowledge.mjs` 仅用于历史 1.7.0 原库筛选，直接运行会覆盖合并结果，之后须运行 `data:refresh` 恢复合并库。

构建产物位于 `dist`，可安装的 `.bin`、`.rpk` 与 SHA-256 校验文件位于 `release`。

`release` 中同时提供带完整语句源记录、筛选脚本与许可证的源码压缩包，便于审核和按 AGPL 要求分发。
