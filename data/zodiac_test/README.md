# 日常一页 · 星座气质测试模块 v1

- 30 道情景题，120 个答案分支
- 10 个性格维度：行动力, 社交性, 理性, 感性, 稳定性, 好奇心, 独立性, 共情力, 竞争性, 适应性
- 12 个星座气质模型
- 534 个分析模板片段

## 文件
- questions.json：题目与权重
- zodiac_profiles.json：12 星座模型
- analysis_templates.json：分析模板
- scoring.js：Vela 可移植计分、排名、分析拼装、生日星座函数
- validation.json：完整性校验

## 推荐结果页层级
主气质星座 → 第二/第三气质 → 10维图谱 → 主分析 → 星座组合 → 突出维度 → 性格组合/矛盾点 → 社交/亲密/工作/压力/决策/隐藏面 → 一句话总结。

> 本测试仅用于娱乐与自我探索，不属于心理诊断、人格测评或科学占星结论。
