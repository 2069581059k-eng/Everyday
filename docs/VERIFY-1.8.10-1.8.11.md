## 二、缺陷 1（P0，已修复于 1.8.11）：知识大全文字不渲染

### 现象
- 阅读类（百科全书/冷笑话/鬼故事）进入后**只有标题和分类标签，正文整块空白**。
- 答题类（脑筋急转弯/十万个为什么）点「查看答案」后，答案框内的**正文仍然空白**（只有红色"答案"标签）。

### 证据（1.8.10 官方包，像素级）
| 截图 | 区域 | 结果 |
| --- | --- | --- |
| `qa-1.8.10/04-kn-item1.png` | 阅读正文区 x30-302 y124-372 | **仅 1 种颜色（纯背景），深色文字 0.00%** |
| `qa-1.8.10/06-kn-item3.png` 等 4 页 | 同上 | 深色文字 0.00% |
| `qa-1.8.10/04-kn-item1.png` | 标题区 y56-116 | 文字正常（5.26%）→ 说明布局与背景色都对，只是正文不显示 |
| 1.8.11 同位置 | 同上 | 正文文字 17.66% / 18.75% / 17.78% / 9.76% |

行带密度对比（x20-316）：

```
1.8.10 阅读页：y60-380 全部 0.0%（除标题行）      ← 正文缺失
1.8.11 阅读页：y80-180 有 25.1/20.3/35.8/18.1%    ← 标题+正文正常
```

### 根因
`src/pages/knowledge/knowledge.ux` 在 `renderQuiz/renderDetail/revealAnswer` 中给
`this.riddleExplain`、`this.riddleAnswer` 赋值，但二者**未在 `export default` 的 `private: {}` 中声明**。
Vela 只把 `private` 中声明的属性作为模板数据源 → `{{riddleExplain}}` 绑定为空（与 1.8.10 已修的同类根因，属遗漏项）。

静态检查确证（修复前）：

```
FAIL  knowledge.ux：赋值但未在 private 声明 → riddleExplain, riddleAnswer
```

### 修复（1.8.11 / 10811）
- `knowledge.ux` 的 `private` 补 `riddleExplain: ''`、`riddleAnswer: ''`。
- 新增 `tools/check-private-data.mjs`：扫描所有页面 `this.X = …` 是否已在 `private` 声明，并接入 `npm test` 防回归。
- 版本三处同步：`package.json` / `package-lock.json` / `src/manifest.json` → 1.8.11 / 10811。
- 构建：`git archive` 独立副本 → `tools/inline-modules.mjs` → `aiot build --enable-jsc` → `tools/verify-rpk.mjs` 通过。

## 三、缺陷 2（P1，未修）：退出测试直接离开应用

- 现象：星象答题页点「退出测试」后**离开应用**（截图呈系统黑白界面，应用米色底仅 0–2%），而非回到首页。
- 1.8.10 与 1.8.11 表现一致；`再测一次`（`router.replace` → 答题页）后再退出仍复现。
- 原因：页面栈由 `router.replace` 逐级替换，`quitTest()` 用 `router.back()` 已无上一页可回。
- 建议：`quitTest()` 改为 `router.replace({ uri: 'pages/index' })`（与其它页「返回主页」一致），列入下一版。

## 五、模拟器环境注意事项（本次踩坑，已写入脚本）

1. **屏幕会进入低功耗态**：截图呈"黑底白字"（平均亮度 45）或整体变暗（142–145），会让所有像素断言失真。
   `KEYCODE_WAKEUP` 常常无效；需在显示区外底部边框轻点（x168,y474）后才恢复。脚本已按平均亮度 ≥170 自动唤醒重试。
2. **`pm clear` 对 Vela 应用存储无效**：知识进度会跨安装残留，页面可能从"第 14 题"之类的中途开始（本次实测序列对应题单第 14–19 条）。
   验收时不要把"期望第 1 题"写成硬断言，应按"当前页是阅读类还是答题类"做模式无关断言。
3. **`@aiot-toolkit/emulator` 的 gRPC 偶发崩溃**（`Cannot read properties of undefined (reading 'image')`，抛在库回调内），需进程级兜底。
4. **期望版本要以 RPK 文件名为准**（`/(\d+\.\d+\.\d+)\.rpk$/`），不要用源码 manifest——否则验收历史版本包必然失败；versionCode 换算为 `major + minor(2位) + patch(2位)`（1.8.11 → 10811）。
5. 截图有效性阈值：平均亮度 180–250 视为正常页面。
